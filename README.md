# Vasukii AR (test build)

Android app for previewing Vasukii plants in your own space.
Pick a plant, pot colour and size, rotate it in 3D, then tap **View in your space** to place it
on your floor through the camera (Google ARCore / Scene Viewer).

This is the first test build: 4 stylised sample plants x 3 pot colours x 3 sizes (generated by code,
not real product scans).

## Get the APK on your phone (no Android Studio needed)

1. Push this repo to GitHub (branch `main`). The workflow **Build Android APK** runs automatically
   (or run it from the Actions tab > *Run workflow*). It takes about 5 minutes.
2. On your phone open `https://github.com/Tushar9850/Vasukii-AR/releases/tag/latest`
   and download `vasukii-ar-debug.apk`.
3. Allow "Install unknown apps" for your browser when asked, then install.
4. Open the app. First time you tap AR it may ask you to install/update **Google Play Services for AR**.

Phone needs: Android 7+, a camera, [ARCore support](https://developers.google.com/ar/devices),
and the Google app installed.

## How it works

- `www/` - the app UI (plain HTML/CSS/JS + `<model-viewer>` for the in-app 3D preview), wrapped by Capacitor.
- `www/models/` - `.glb` files named `<plant>_<pot>_<size>.glb`. `www/plants.json` is the catalogue.
- `android/.../SceneViewerPlugin.java` - small native plugin that launches Google Scene Viewer with the model.
- Scene Viewer must download the model from a public **https** URL. `www/app.js` (`MODEL_BASE_HTTPS`)
  points at this repo through jsDelivr, so **models must be pushed to `main` before AR works**.
  (jsDelivr caches branch files for up to ~12 h; after changing a model use
  `https://purge.jsdelivr.net/gh/Tushar9850/Vasukii-AR@main/www/models/<file>.glb`.)

## Change / add plants

```bash
pip install numpy
python3 tools/make_plants.py     # regenerates www/models and www/plants.json
```
To use real models, drop `.glb` files in `www/models/` with the same naming and edit `www/plants.json`.
Keep each file small (< 5 MB) and in metres at real-world scale so AR size is correct.

## Local dev

```bash
npm install
npm run serve        # preview the UI in a desktop browser (AR button only works on phones)
npm run sync         # copy web assets into the Android project
cd android && ./gradlew assembleDebug   # needs Android SDK + JDK 21
```
